# Molecules

Components built from two or more atoms: tabs, dropdown, modal, form, tooltip, search bar, pagination, breadcrumbs.

## Empty by design

This folder ships empty so you are not tempted to fork stale specs that may not match your UI. Add molecules your product actually ships, using the template at [`../../COMPONENT-SPEC-TEMPLATE.md`](../../COMPONENT-SPEC-TEMPLATE.md). A small accurate spec layer beats a comprehensive stale one.

## Suggested order for SMB products

1. `form.md` (label + input + helper text + error)
2. `search-bar.md` (icon + input + clear button)
3. `modal.md` (backdrop + container + header + actions)
4. `tooltip.md`
5. `tabs.md`
6. `dropdown.md`
7. `pagination.md`
8. `breadcrumbs.md`
