# Organisms

Larger composite components built from molecules and atoms: navigation, table, page header, content panel, card grid, site footer.

## Empty by design

This folder ships empty so you are not tempted to fork stale specs that may not match your UI. Add organisms your product actually ships, using the template at [`../../COMPONENT-SPEC-TEMPLATE.md`](../../COMPONENT-SPEC-TEMPLATE.md).

## Suggested order for SMB products

1. `navigation.md` (primary nav + mobile nav + active state rules)
2. `site-footer.md`
3. `page-header.md` (title + meta + actions area)
4. `data-table.md` (header row, row states, sorting, pagination wiring)
5. `card-grid.md`
6. `marketing-hero.md` (reference for any landing page)
