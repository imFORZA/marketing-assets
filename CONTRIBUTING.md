# Contributing

This repo is a starter pack, not a shared community standard. The intended workflow is:

1. **Fork** the repo under your own account or organization.
2. **Adapt** every template to your business. Replace our fictional examples with your real answers.
3. **Version** your work with regular commits. Write commit messages that capture why something changed, not just what.
4. **Load** your filled-in repo into your AI agents (Claude Projects, ChatGPT Projects, Gemini Gems, OpenClaw, Hermes, Manus, or any custom workflow).

## If you want to contribute back

If you improve a template in a way that would help other small businesses (a clearer structure, a better prompt, a useful new section), we welcome pull requests to the public repo.

Guidelines:

- **Keep it generic.** Contributions should work for any small business, not just yours. Strip out brand-specific details before opening a PR.
- **No tool lock-in.** Markdown and JSON only. No proprietary formats.
- **Match the voice.** Practitioner, plain-language, direct. No jargon. No em dashes (commas, periods, colons instead). Stats lead with the number.
- **Small, focused PRs.** One improvement per PR. Write a short description of the problem and the fix.
- **Include a worked example.** If you add a new template, include a fictional filled-in version alongside the blank one so adopters can see what a good answer looks like.

## What won't be merged

- AI-generated content with no human review.
- Promotional content for specific tools or vendors. Tool recommendations that already live in a template are fine when they are balanced and include free and paid options.
- Sweeping structural changes to the 10-asset framework. The framework is opinionated on purpose.

## Questions

If you are not sure whether something belongs here, open an issue before writing a PR.

## Reporting issues

Found a bug, a typo, or an unclear section? Open an issue. Be specific about the file and the problem.
