# 09, Data, Analytics, and Performance Library

The Intelligence Layer opens here. You have written down who, how, what, where, and why. Now you write down how you know it is working.

## What this layer does

This folder is the measurement layer. It names the tools, the events, the KPIs, and the assets that compound. It tells every agent the exact definition of "converted," "booked," "qualified," and "won."

## Files in this folder

- `ANALYTICS.md`, Tracking stack inventory, KPIs by funnel stage, dashboard definitions, reporting cadence, and data ownership.
- `TRACKING-PLAN.md`, Event taxonomy, conversion event definitions, UTM conventions, attribution model, and consent notes.
- `TOP-PERFORMERS.md`, Curated library of top-performing assets with performance data attached. Training fodder for agents.

## Build order inside this layer

1. Set the stack and KPIs in `ANALYTICS.md` first. If the team disagrees on the definition of a lead, no dashboard will ever be trusted.
2. Build the `TRACKING-PLAN.md` once the KPIs are stable. Every event name, every UTM convention.
3. Populate `TOP-PERFORMERS.md` monthly. Feed patterns back into `10-brand-brain` so agents write from what actually works.

## What this folder feeds into

- `10-brand-brain` loads top-performer examples into content generation prompts.

## Next layer

After this folder is filled in, move to `10-brand-brain` to tie everything together into an agent-ready operating system.
